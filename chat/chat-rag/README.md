# RAG 检索增强生成示例模块

本模块展示了 LangChain4j 中 RAG（Retrieval Augmented Generation，检索增强生成）的常见使用方式。

## 功能介绍

RAG 是一种将外部知识库检索和大模型生成相结合的技术，可以有效解决大模型幻觉、知识过时等问题，提升回答的准确性。

## 示例列表

| 示例类 | 功能说明 |
|--------|----------|
| `FileLoadRagDemo` | 文件加载RAG演示，支持从本地目录加载 TXT/PDF/DOCX 等文档，构建知识库进行问答 |
| `MemoryRagDemo` | 带记忆的RAG演示，将对话记忆与RAG检索结合，支持上下文关联的多轮问答 |


## 扩展建议

1. **向量数据库替换**：实际生产环境可以替换为 Redis、Elasticsearch、Pinecone 等专业向量数据库
2. **文档加载优化**：支持从 OSS、数据库、网页等更多数据源加载文档
3. **检索策略优化**：可以使用重排序（Rerank）、混合检索等方式提升召回准确性
4. **分块策略优化**：根据文档类型选择合适的分块大小和重叠长度
