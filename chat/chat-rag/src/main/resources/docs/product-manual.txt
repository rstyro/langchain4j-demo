# 公司产品手册
## 产品介绍
我们的产品是一款基于大语言模型的智能客服系统，主要功能包括：
1. 自动回复用户常见问题，准确率可达98%
2. 支持多渠道接入，包括网站、APP、微信公众号、企业微信
3. 内置知识库管理功能，支持一键导入导出
4. 支持多轮对话记忆，上下文理解能力强
5. 支持自定义工作流，满足不同业务场景需求
